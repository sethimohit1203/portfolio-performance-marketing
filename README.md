# Performance Marketing Portfolio - Mohit Seth

A modern, responsive web portfolio showcasing performance marketing expertise and achievements.

## 🚀 Features

- **Modern Design**: Clean, professional design with gradient animations and smooth transitions
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**: Animated skill bars, floating cards, smooth scrolling navigation
- **Performance Focused**: Fast loading with optimized animations and effects
- **Contact Form**: Functional contact form with validation
- **SEO Optimized**: Proper meta tags and semantic HTML structure

## 📱 Sections

- **Hero Section**: Eye-catching introduction with animated statistics
- **About**: Professional background and key achievements
- **Skills**: Technical expertise across advertising platforms and tools
- **Experience**: Career timeline with detailed accomplishments
- **Portfolio**: Case studies with performance metrics
- **Contact**: Professional contact information and form

## 🛠 Technologies Used

- **HTML5**: Semantic markup and accessibility
- **CSS3**: Modern styling with flexbox, grid, and animations
- **JavaScript**: Interactive functionality and smooth user experience
- **Font Awesome**: Professional icons
- **Google Fonts**: Clean typography with Inter font family

## 🔧 Setup & Usage

1. Clone the repository
2. Open `index.html` in a web browser
3. Or serve using a local web server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`
